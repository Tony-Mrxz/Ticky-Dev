# Ticky - Premium Desktop Companion

Ticky is a gorgeous, minimal floating desktop clock, stopwatch task focus manager, auto-minimization ball, and borderless Spotify integration widget designed for Windows.

Developed by **Tony Mrxz**.

## Core Features
- **Stays on Top & Desktop Pinning:** Fully configurable to match your desktop layout.
- **Inactivity Ball Mode:** Automatically minimizes to a checkmark ball, reminding you of random tasks from your list when hovered.
- **Focus Stopwatch:** Select a task, hit focus, and Ticky collapses to track your progress.
- **Spotify Mini Player:** Embedded timeline tracking, custom SVG dots menu, and rotating album vinyl art.

## Tech Stack
- **Core:** Python 3 + PySide6 (Qt for Python)
- **Styling:** Custom QSS (Qt Style Sheets) stylesheet architecture
- **System Integrations:** Windows Registry for auto-startup hooks, win32 API wrapper modules
- **Music API:** Spotify Web API Client credentials flow
